# DOLVE // Hardware & Lifestyle Tecnológico de Vanguardia

Sitio web interactivo de alto impacto visual (estilo ASUS ROG / Cyberpunk) que combina **Landing Page**, **Catálogo de Productos** interactivo con vista rápida y carrito de pedidos por WhatsApp, y magazine de novedades **Dolve Pulse**.

## 🚀 Características
- **HTML5 semántico** con estructura moderna y SEO optimizado.
- **CSS3 Vanilla**: Diseño responsivo, modo oscuro con gradientes neón y tokens de diseño personalizados.
- **Efectos dinámicos al hacer scroll**:
  - Barra de lectura en tiempo real en la parte superior.
  - Aparición suave de tarjetas con `IntersectionObserver`.
  - Contadores numéricos animados en la sección de estadísticas.
- **Catálogo Interactivo**:
  - Filtro por categorías en tiempo real.
  - Buscador dinámico de productos.
  - Modal de Vista Rápida (*Quick View*) con especificaciones técnicas completas.
- **Carrito de Compras / Pedidos**:
  - Drawer deslizante con cálculo de subtotales.
  - Checkout integrado para enviar el pedido listo y formateado por WhatsApp.
- **Blog Dolve Pulse**:
  - Lector de artículos completo integrado en modal.

## 🛠️ Tecnologías
- HTML5
- CSS3 (Vanilla)
- JavaScript (ES6+)

## 💻 ¿Cómo correr este proyecto en otra PC?

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/nadiesss/dolve-page.git
   cd dolve-page
   ```

2. **Abrir el proyecto:**
   - Simplemente abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Brave).
   - O si prefieres un servidor local con Python:
     ```bash
     python -m http.server 5500
     ```
     Y abre `http://localhost:5500` en tu navegador.
